# shop-ui

可选的商店客户端界面，模组 id 是 `shopmod-ui`。不装也能进服。商店规则仍在 MinecraftShopMod。

支付货币只有银行券，以及快照里实际出现的个人银行券。铜锭和钻石不能选。商品单价用当前货币的实时牌价换算；没有牌价就显示「暂无牌价」。

The optional shop screen. Pay with central bank notes or a personal note from the snapshot. Copper and diamonds are not selectable. A missing live quote stays 暂无牌价.
