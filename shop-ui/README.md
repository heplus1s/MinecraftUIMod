# shop-ui

这里留给以后的商店界面。现在没有商店玩法，也不会打出 jar。

服务器核心不在这个仓库。商店如果以后要做，规则仍放在对应的模组里，这里只放可选的客户端界面。

This folder is reserved for a future shop screen. There is no shop gameplay here, and this folder is not a Gradle module, so it does not build a jar.

Server rules stay in their own mods. When a shop exists, this repository will only hold the optional client screen.
